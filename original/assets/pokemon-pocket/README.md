# Pokémon Safari – Kartenbilder und Illustrationen

Dieses Verzeichnis enthält die vom Lehrer bereitgestellten Bilder für Pokémon Pocket in der Oase.

## Hochladen
1. Das ZIP `pokemon-pocket-alle-bilder-github-2026-11-15.zip` lokal entpacken.
2. Darin den Ordner `original/assets/pokemon-pocket/` öffnen.
3. **Nur die 41 .webp-Dateien** auswählen und mit **Add file → Upload files** in **diesen GitHub-Ordner** hochladen.
4. Mit **Commit changes** bestätigen.

Die Dateien müssen unmittelbar in diesem Verzeichnis liegen, beispielsweise `original/assets/pokemon-pocket/yanma.webp`, `original/assets/pokemon-pocket/card-back.webp`, `original/assets/pokemon-pocket/pocket-hero.webp`. Nicht die ZIP hochladen und keinen zweiten Unterordner `pokemon-pocket` anlegen.

Die Software in `original/assets/pokemon-pocket-engine.js` verwendet eine **unendliche Energiezone**; bei jedem Verbrauch wird die nächste Energie zufällig aus den Energietypen des Decks gezogen.
